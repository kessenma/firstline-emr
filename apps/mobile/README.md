# MedFlow Mobile App

This mobile application is a clone of the MedFlow web app (located in `apps/web`) with some slight modifications to adapt it for mobile use. The web app is built with Next.js, and its views are constructed using the API endpoints in `apps/web/app/api` and components in `apps/web/components`.

## Getting Started

First, ensure you have Node.js >=20 installed.

Clone the repository and navigate to the mobile app directory:

```bash
git clone https://github.com/<your github username>/med-flow.git
cd med-flow/apps/mobile
npm install
```

To start the development server:

```bash
npm start
```

For iOS:

```bash
npm run ios
```

For Android:

```bash
npm run android
```

## Documentation

All documentation generated by LLMs for this mobile app should be placed inside the `docs/` folder. This includes API documentation, component guides, and any other relevant docs.

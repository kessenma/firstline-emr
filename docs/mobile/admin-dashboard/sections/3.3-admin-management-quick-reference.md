## API Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|

## User Workflows

### Add Admin
1. Enter email in search field
2. Tap "Search" button
3. Tap "Add Admin" on search result
4. Confirm in dialog
5. Success notification + auto-refresh

### Remove Admin
1. View admin list
2. Tap "Remove Admin" on admin card
3. Confirm in dialog
4. Success notification + list update

## Error Messages

### Common Errors
- "No authentication token found" → User not logged in
- "Failed to fetch admins" → API/network issue
- "No users found with that email" → Search returned empty
- "Failed to add admin" → Add operation failed
- "Failed to remove admin" → Remove operation failed

### Solutions
1. Check network connectivity
2. Verify authentication token
3. Check API endpoint availability
4. Review server logs
5. Use retry button in UI

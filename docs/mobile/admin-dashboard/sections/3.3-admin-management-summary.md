## Technical Implementation

### Architecture Pattern
- **MVVM** (Model-View-ViewModel)
- ViewModel handles all business logic
- View handles UI and user interactions
- Separation of concerns maintained

### State Management
```typescript
ViewModel State:
- admins: AdminUser[]
- searchResults: SearchResultUser[]
- isLoadingAdmins, isSearching
- isAddingAdmin, isRemovingAdmin
- error states

Component State:
- removingAdminId (for loading indicators)
- addingUserId (for loading indicators)
```

### API Integration
- `GET /api/admin/GET/existing-admins` - Fetch admins
- `GET /api/admin/GET/search-users` - Search users
- `POST /api/admin/POST/admin-mgmt-add` - Add admin
- `POST /api/admin/POST/admin-mgmt-remove` - Remove admin

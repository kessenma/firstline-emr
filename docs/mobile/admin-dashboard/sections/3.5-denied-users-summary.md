### Architecture Pattern
- **MVVM** (Model-View-ViewModel)
- ViewModel handles all business logic

- Clean separation of concerns

### State Management
```typescript
ViewModel State:
- users: DeniedUser[]
- isLoading, isRefreshing, isLoadingMore
- currentPage, totalPages, hasMore
- selectedUserIds, isAllSelected
- error: string | null
```

## Notable Design Decisions

### 1. Reinstate vs. Delete
**Decision**: Implemented reinstate (re-approve) only, not permanent delete  
**Rationale**: 
- Reinstate is reversible (can deny again)
- Aligns with principle of least destruction
- Delete can be added later if needed

### 2. Pagination
**Decision**: 20 users per page  
**Rationale**:
- Balance between performance and UX
- Prevents overwhelming the user
- Reduces initial load time

### 3. Info Banner
**Decision**: Yellow banner explaining denied status  
**Rationale**:
- First-time users may not understand the section
- Provides context without cluttering UI
- Can be dismissed mentally after first view

### 4. Account Type Colors
**Decision**: Blue (Doctor), Purple (Triage), Pink (Evac)  
**Rationale**:
- Consistent with existing sections
- High contrast for accessibility
- Clear visual differentiation
